# EN 🇺🇸

# Mullvad Browser for Arch Linux

A package project maintained by me (Gabriel) to make it easier to install Mullvad Browser on Arch Linux.

**Maintainer:** Gabriel Jesus | better known as Gabriel pirocudo (`@gabrielsecarch`)

## Project Goals

- Provide an Arch Linux-compatible `PKGBUILD`.
- Install the stable version of Mullvad Browser from the original project's official sources.
- Preserve the upstream integrity and signature checks.
- Document the installation, testing, and updating procedures.

## Official Upstream

- Website: https://mullvad.net/browser
- Source code repository: https://github.com/mullvad/mullvad-browser
- Downloads for Linux: https://mullvad.net/en/download/browser/linux

## Security

The package must use official releases from the original developer, validate their SHA-256 checksums, and verify OpenPGP signatures using a trusted signing key from the original developer.

Never disable signature verification to work around an error.
